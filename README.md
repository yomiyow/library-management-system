A Java-based **Library Management System (LMS)** developed as a **final project for Object-Oriented Programming 1 (2nd year, 1st semester)** at **Bulacan State University**.  
This system streamlines library operations and provides students, teachers, staff, and librarians with an intuitive platform to manage and access library resources.

## 🚀 Features

### 🔑 Authentication
- Role-based **Sign Up** and **Login** (Student, Teacher, Staff, Librarian)

### 👩‍🏫 Librarian Functions
- Add, update, delete, and search books  
- Manage library members  
- Track and manage borrowed books

### 🎓 User Functions (Student/Teacher/Staff)
- Browse and search books by title, author, category, or ISBN  
- Borrow books with a 15-day due period  
- View personal borrowed book list

### 🔍 Search & Filters
- Filter by category  
- Keyword-based search

## 🛠️ Tech Stack
- **Java (Swing GUI)**  
- **MySQL** – database  
- **JDBC** – database connection  
- **FlatLaf** – modern UI look and feel
